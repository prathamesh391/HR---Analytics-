# HR Analytics Dashboard — Power BI

## Project Overview
This project presents an HR Analytics Dashboard built using Power BI to explore workforce data and support data-driven HR analysis.

## Objectives
- Analyze available HR metrics.
- Identify workforce patterns and trends.
- Present key insights through interactive visualizations.

## Tools & Technologies
- Power BI
- Power Query
- DAX

## Project Files
- Power BI dashboard file, if included
- Dashboard screenshots
- Project documentation

## How to View
Open the screenshots in this repository to preview the dashboard. If the `.pbix` file is included, download it and open it using Power BI Desktop.
